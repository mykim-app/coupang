쿠팡 가격 알림

쿠팡 API 키 등록 전입니다. 상품은 먼저 등록해 둘 수 있고, 가격은 키 등록 후 자동으로 조회됩니다.

쿠팡 API는 상품번호만으로 조회할 수 없어, 검색어로 찾은 상위 10개 중 같은 상품번호를 찾아 가격을 확인합니다. 브랜드·용량을 넣어 구체적으로 적어 주십시오. 등록하면 확인 메일을 보내고, 이후 가격이 바뀔 때마다 메일로 알려 드립니다.
파트너스 링크: 쿠팡 파트너스 → [링크 생성]에서 상품을 검색해 만든 단축 URL 또는 "이미지+텍스트" HTML 코드를 붙여 넣으면 상품 이미지와 함께 아래와 같은 링크 카드로 표시됩니다.
